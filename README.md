# سمسار مصر — V3

نسخة مطوّرة للعبة محاكاة العقارات المصرية.

## الجديد
- البداية للحسابات الجديدة: **500,000 ج.م**.
- Dark Mode كامل.
- تسجيل الدخول للاعب بـ **Username + Password فقط** في واجهة اللعبة.
- اسم المستخدم فريد ولا يمكن تكراره.
- كل لاعب له حفظ مستقل في Supabase.
- Top 10 فقط في الـLeaderboard.
- حماية أفضل لبيانات اللاعبين: الـLeaderboard لا يرجّع بيانات الحساب الكاملة.
- مناطق مصرية أكثر: شبرا، عين شمس، الهرم، مدينة نصر، مصر الجديدة، المعادي، التجمع الخامس، الشيخ زايد، 6 أكتوبر، العاصمة الإدارية، الإسكندرية، سيدي بشر، الساحل الشمالي، العلمين الجديدة، مدينتي، الرحاب.
- أنواع عقارات أكثر: شقق، استوديوهات، محلات، فلل، قصور، شاليهات.
- مفاوضة، شراء، ترميم، بيع، تطوير المكتب، سمعة، مستويات وإنجازات.
- إزالة الصوت بالكامل: لا يوجد Sound setting ولا زر للصوت.
- تحسين أزرار اللعبة وربطها بالأحداث مباشرة.

## قبل النشر على Vercel
1. في Supabase افتح **SQL Editor** وشغّل كل `supabase.sql`.
2. في Supabase افتح **Authentication → Providers → Email** واقفل **Confirm email**؛ لأن اللعبة تستخدم Username + Password فقط أمام اللاعب.
3. افتح `app.js` وضع:
   - `SUPABASE_URL` = Project URL.
   - `SUPABASE_ANON_KEY` = Publishable/anon key فقط.
4. ارفع الملفات الخمسة إلى GitHub بنفس الأسماء أو حدّث الملفات في المستودع الحالي.
5. في Vercel اعمل Redeploy للمشروع.

## مهم لحسابك القديم
الـdefault الجديد 500,000 ينطبق على الحسابات الجديدة. لو حسابك الحالي ما زال عنده 85,000، شغّل مرة واحدة في Supabase SQL Editor:

```sql
update public.game_profiles
set cash=500000, net_worth=500000
where username='اسم_المستخدم_بتاعك';
```

لا تشغّل الاستعلام لو عايز تحتفظ برصيد الحساب الحالي.

## ملاحظة عن Username + Password
Supabase Auth يعتمد داخليًا على بريد تقني مخفي، لكن اللاعب لا يرى أو يدخل أي Email. لذلك لازم يكون **Confirm email** مقفول.
