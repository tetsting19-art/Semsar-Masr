# سمسار مصر — V4

V4 هي إعادة تطوير كبيرة لاقتصاد اللعبة والواجهة.

## أهم ما في V4
- بداية الحسابات الجديدة: 500,000 ج.م.
- تفاوض له حد أدنى منطقي بدل استغلال الأسعار.
- لا يمكن شراء عقارات أكثر من سعة المكتب.
- تطوير المكتب يفتح سعة عقارات أكبر.
- أسعار السوق تتحرك مع الأيام وأحداث السوق.
- أيام وشهور وسنين داخل اللعبة.
- قروض بفوائد ومدد سداد مختلفة.
- الإيجار من NPCs وليس من لاعبين حقيقيين.
- طلبات إيجار من NPCs بعد امتلاك العقار.
- عقود شهرية أو سنوية.
- قبول / رفض / تفاوض على عروض الإيجار.
- دخل الإيجار يُدفع شهريًا مع مرور الأيام.
- عقود الإيجار تنتهي ويمكن أن تأتي عروض جديدة.
- صيانة مقسمة: الهيكل، السباكة، الكهرباء، التشطيبات، الواجهة والحديقة.
- لكل جزء مستويات تطوير، والتطوير يرفع قيمة العقار.
- الصيانة مكلفة والإهمال يقلل حالة العقار وقيمته.
- مستثمرون NPC يظهرون كمنافسين في السوق.
- Leaderboard Top 10.
- الضغط على اسم اللاعب يعرض الكاش وصافي الثروة وعدد العقارات وإجمالي الأرباح.
- واجهة Dark Luxury محسنة ومتجاوبة للموبايل.
- كل النصوص والعناوين بالعربي، وكل الأرقام English Numbers.

## التشغيل
1. افتح Supabase > SQL Editor > New query.
2. شغّل `supabase.sql` بالكامل.
3. Authentication > Providers > Email: اقفل Confirm email.
4. افتح `app.js` وضع Project URL و Publishable/anon key.
5. ارفع `index.html`, `style.css`, `app.js`, `supabase.sql`, `README.md` إلى GitHub.
6. Vercel يعمل Deploy جديد.

## ملاحظات
- `SUPABASE_ANON_KEY` يجب أن يكون مفتاح النشر/anon فقط، وليس service_role.
- لا توجد لوحة Admin في هذه النسخة؛ أدوات الإدارة يمكن إضافتها لاحقًا بصلاحيات منفصلة.
- نظام الأيام يتقدم بزر "اليوم التالي". كل 30 يومًا تتم معالجة دخل الإيجارات وأقساط القروض وتكلفة الصيانة.
